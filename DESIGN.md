# DESIGN.md — oechsner.dev

> **International Typographic Style (Swiss).** A strict twelve-column grid, one neo-grotesque
> family, flush-left ragged-right setting, large numerals for indexing, black on white, and a
> single signal red. This document replaces the earlier "Quiet authority" dark/serif spec.

---

## 1. Concept

**Philosophy** — *Information first, ornament never.* Every element sits on a column of the
grid; hierarchy is made with size, weight and black rules, not with colour, shadow or shape.
Whitespace is structural: the empty columns to the left of a text block are part of the
layout, not leftovers.

**Tone**: rigorous · asymmetric · flat · numbered · unhurried.

**Positioning**: personal portfolio and technical blog for Jonas Öchsner. The site leads with
the writing, not the author — see §10.

---

## 2. Palette

Light is the only theme. All colours are variables in `src/app.css`; **no component
hard-codes a colour** (`src/lib/components/rpm/` is the one exception, it renders on its own
plate).

| Role | Token | Value |
| --- | --- | --- |
| Paper | `--bg` | `#ffffff` |
| Wells (code, tinted panels) | `--bg-deep`, `--surface` | `#f3f3f1` |
| Headings, rules, UI text | `--text`, `--line-strong` | `#0a0a0a` |
| Body copy | `--text-secondary` | `#2e2e2e` |
| Meta text | `--text-muted` | `#666666` (5.7:1 on white, 5.2:1 on `--surface`) |
| Hairlines | `--line` | `#d2d2cf` |
| **Signal red** | `--accent` | `#e30613` (4.9:1 on white) |
| Red, pressed | `--accent-dim` | `#b30010` |
| Chart second series | `--series-cool` | `#0b4fa8` |

Red is used for: index numerals, the brand square, current-page underline, list markers,
hover states, selection, the bar of a blockquote. It is never a fill behind running text and
never used decoratively in quantity. `--text-muted` is meta text only; re-measure it against
both `--bg` and `--surface` if it changes.

---

## 3. Typography

One family: **Inter** (variable, self-hosted via `@fontsource-variable/inter`), plus
**JetBrains Mono** for code only. Latin-ext is included, which the name *Öchsner* needs.

| Role | Size | Weight | Tracking | Line-height |
| --- | --- | --- | --- | --- |
| Display (home lead title) | `clamp(2.75rem, 8.4vw, 7rem)` | 800 | `-0.055em` | 0.94 |
| Page title (About, Contact, Projects) | `clamp(3rem, 10vw, 8.5rem)` | 800 | `-0.055em` | 0.92 |
| Post title | `clamp(2.25rem, 6.4vw, 5.25rem)` | 800 | `-0.05em` | 0.96 |
| Index numeral (sections) | `clamp(2.5rem, 5.2vw, 4.5rem)` | 800 | `-0.05em` | 0.85 |
| Row title | `clamp(1.375rem, 2.4vw, 1.875rem)` | 800 | `-0.035em` | 1.08 |
| Standfirst / lede | `1.125–1.5rem` | 500 | `-0.015em` | 1.4 |
| Body / prose | `1rem` / `1.0625rem` | 400 | 0 | 1.6 / 1.7 |
| Meta, labels | `0.75–0.8125rem` | 600–700 | 0 | 1.4 |

**Setting**: flush left, ragged right, everywhere — no justification, no centring. Sentence
case; no uppercase tracking. Measure: `--measure` 62ch, `--measure-prose` 68ch.
Tabular figures (`tnum`) on numerals and dates.

**Forbidden**: a second text family, italics for emphasis in UI, text shadows, gradients on
type, faux weights.

---

## 4. Grid

Twelve columns, `--col-gap: 1.5rem`, container `1360px` with a fluid `--gutter`
(`clamp(1rem, 3.2vw, 2.5rem)`). `.grid` makes any element a 12-column grid.

- **Sections (`Rail`)**: a 2px black rule, then the label and its CSS-counted red numeral in
  columns 1–3, the content in 4–12. Numerals are generated by a CSS counter (`section`) so the
  index can never drift; page-level rails (`level={1}`) are not counted.
- **Home**: masthead row (greeting 1–6, tagline and links 7–12); lead post under a 6px rule
  with its running number and eyebrow in 1–3, the title across 4–12, facts in 1–3, standfirst
  in 4–9 and a greyscale cover in 10–12; then the ruled index of rows.
- **Post**: header facts (date, reading time, depth, tags) in columns 1–3, title and standfirst
  in 4–12; under a 6px rule the sticky outline takes 1–3 and the prose 4–10.
- **Footer**: four columns — name, pages, legal, colophon — on the same lines as the content.

Below 768px every grid collapses to one column; label sits above body. Nothing scrolls
horizontally down to 360px.

---

## 5. Spacing

`--s-1`…`--s-11` (0.25rem doubling up to 11rem). Section gaps `--gap-section` (6rem, 4rem,
3rem by breakpoint). Rules, not boxes, separate things: 1px hairline for rows inside a
section, 2px black for section starts, 6px black for the page's major break (lead post,
post header, footer).

## 6. Shape and depth

None. Radius 0 everywhere, no shadows (`--shadow-*` are `none`), no blur, no gradients. Focus
is a 2px black ring offset by 2px of paper (`--focus-ring`).

## 7. Motion

Short and functional: a 420ms rise-and-fade on first paint (`.enter`), a one-shot scroll
reveal on sections, 120–200ms colour changes on hover. Hover turns text or fills red; images
go from greyscale to colour. `prefers-reduced-motion` removes all of it.

## 8. Components

- **Header** — sticky white bar, red square + name left, nav right. Current page: 2px red
  underline. Below 40em the secondary links fold into a framed "More" menu.
- **Buttons** — rectangles with a 2px black border; primary is filled black. Hover: red.
- **Tags** — outlined rectangles; pressed = red fill.
- **ArticleRow** — ruled row: running number (oldest = 01), title, summary, meta with red
  slashes, greyscale thumbnail.
- **Entry** (experience, projects) — hairline-separated blocks with red list markers.
- **Prose** — h2 opens with a 2px rule; links are black with a 2px red underline; blockquotes
  are 6px red-barred, set large; code on `--bg-deep` with a black top rule.
- **Outline** — borderless list, 4px red bar on the active heading, 3px progress track.
- **Icons** — inline SVG in `Icon.svelte`. No emoji, no icon font.

## 9. Don'ts

1. No second accent colour. 2. No dark mode or theme toggle. 3. No rounded corners, shadows
or gradients. 4. No centred or justified text. 5. No uppercase letterspaced labels. 6. No
colour in components that is not a token. 7. No imagery beyond post covers; covers are set in
greyscale until hovered.

## 10. Content-first hierarchy

The largest type on the site is always a piece of writing. On the home page the lead post's
title is the display size; the masthead above it is body-sized; the author's name appears only
in the header and footer at 15px. The lead's running number is capped below the title's size.
Page titles on About/Contact/Projects are large because those pages are the content.

## 11. Colophon copy

The footer colophon is editable text in `Footer.svelte`; keep it factual.
